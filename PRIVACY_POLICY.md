# Privacy Policy — TG Media Library

Last updated: 13 September 2026

TG Media Library is an independent Android application that lets a user connect their own Telegram account and browse, filter, play, download and share media from that account. TG Media Library is not affiliated with, endorsed by, or an official application of Telegram.

## Data the app accesses

To provide its core functionality, the app may process:

- Telegram API ID and API Hash supplied by the user;
- Telegram account authentication information required by Telegram/TDLib, such as phone number, login code and, when enabled by the user, Telegram two-step verification credentials;
- Telegram chat/channel metadata needed to identify conversations;
- media and related metadata from the user's Telegram account, including videos, animations, video notes, filenames, captions, dates, sizes and thumbnails;
- app-local preferences such as filters, presets and the privacy-lock PIN verifier.

## How data is used

The data is used only to provide the functions requested by the user: authentication with Telegram, media indexing, playback, filtering, downloading, sharing and local privacy protection.

## Storage and security

TG Media Library does not operate a developer backend for user content and does not upload Telegram media or credentials to a server controlled by the developer.

Sensitive app credentials and the local TDLib database encryption key are protected using Android Keystore-backed encryption. The privacy PIN is not stored as plaintext; the app stores a salted password-derived verifier protected by Android Keystore-backed storage.

Telegram media may be downloaded temporarily to the device when required for playback, download or sharing. Temporary copies and caches are removed by the app as part of its privacy controls. Files that the user explicitly saves to the device's Downloads area remain on the device until the user deletes them.

## Third-party processing

The app communicates directly with Telegram through TDLib and Telegram's services. Information sent to or received from Telegram is processed by Telegram under Telegram's own terms and privacy policy. The developer of TG Media Library does not control Telegram's data processing practices.

## Data sharing

TG Media Library does not sell user data. The app does not share user data with the developer or advertising/analytics providers. Data is transferred to Telegram as necessary to authenticate and access the user's Telegram account. When the user explicitly chooses to share media using Android's sharing functionality, the selected media is provided to the destination application chosen by the user.

## Analytics and advertising

TG Media Library contains no advertising SDK and no developer-operated analytics SDK.

## Account deletion and local data deletion

TG Media Library does not create or host a separate developer account. Telegram accounts are managed by Telegram. Users can remove TG Media Library's local data at any time using Android's app storage controls or by uninstalling the app. This removes app-local credentials, encrypted TDLib data, PIN data, filters and caches. Files explicitly exported by the user to Downloads are outside the app's private storage and must be deleted by the user if desired.

## Children

TG Media Library is not directed to children.

## Changes to this policy

This policy may be updated when the app's functionality or data practices change. The latest version will be published with the application's public project documentation.
